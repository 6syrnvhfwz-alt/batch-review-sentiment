# 批量电商评价情感分析工具

> 基于 Ollama 本地大模型 + Python，自动批量识别电商客户评价的情感倾向，导出负面评价并提取高频问题关键词，帮助运营团队快速定位产品痛点。

## 🎯 项目目标

**解决一个问题**：运营每天要从几百上千条客户评价里，手动翻出差评、归类问题、统计占比，耗时又容易遗漏。

**本工具的价值**：一条命令跑完，自动完成"情感分类 → 差评导出 → 高频问题识别"全流程，效率提升 **10 倍以上**。

## ✨ 核心功能

| 功能 | 说明 |
|---|---|
| 🔄 多格式支持 | 同时支持 CSV 和 JSON 两种数据输入格式 |
| 🤖 本地大模型 | 使用 Ollama + qwen2:7b，数据不出本机，隐私安全 |
| 📊 情感分析 | 自动判断每条评价是正面/负面/中性 |
| 📉 差评导出 | 单独提取负面评价，附带 AI 判定理由 |
| 🔑 关键词提取 | 双重方法：词频统计 + AI 问题类别归类 |
| 📈 进度条显示 | 使用 tqdm 实时显示处理进度 |
| 🛠️ 命令行参数 | 支持自定义输入/输出文件，灵活配置 |

## 🛠️ 技术栈

- **Python 3.11**
- **Ollama**：本地大模型运行框架
- **qwen2:7b**：阿里开源大语言模型
- **requests**：HTTP 请求库
- **tqdm**：进度条库
- **csv / json**：标准库数据处理
- **argparse**：标准库命令行参数解析

## 📦 快速开始

### 1. 安装依赖

```bash
pip install requests tqdm
```

### 2. 启动 Ollama 服务

```bash
# 先确保已下载 qwen2:7b 模型
ollama pull qwen2:7b

# 启动 Ollama 服务
ollama serve
```

### 3. 准备数据

支持两种格式：

**CSV 格式**（`评价数据.csv`）：
```
id,评价内容
1,衣服质量很好 穿着很舒服
2,发货太慢了 差评
```

**JSON 格式**（`评价数据.json`）：
```json
[
  {"id": "1", "评价内容": "衣服质量很好 穿着很舒服"},
  {"id": "2", "评价内容": "发货太慢了 差评"}
]
```

### 4. 运行脚本

```bash
# 默认跑 CSV
python batch_sentiment_v2.py

# 指定 JSON 文件
python batch_sentiment_v2.py --input 评价数据.json

# 指定输出文件名
python batch_sentiment_v2.py --input 评价数据.csv --output 结果.csv

# 开启 AI 关键词提取
python batch_sentiment_v2.py --input 评价数据.csv --keywords
```

## 💡 项目亮点

1. **零成本本地运行**：使用 Ollama 在本地跑大模型，无需付费 API，企业内网可部署
2. **数据隐私安全**：所有评价数据不离开本机，满足企业数据安全要求
3. **双重关键词提取**：既有基于词频的快速方法，也有 AI 语义分析，精度与速度可平衡
4. **完整的工程化结构**：支持命令行参数、进度条、错误处理、多格式兼容
